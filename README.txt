POLURU LAKSHMAN - CSP MINI PROJECT WEBSITE

Files:
- index.html: website homepage
- assets/: your five uploaded project photographs

Preview:
Open index.html in Chrome or Edge.

Publish as a GitHub Pages website:
1. Sign in to GitHub and create a NEW public repository, for example lakshman-csp.
2. Upload index.html and the complete assets folder (keep the folder name assets).
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. Your website URL will be shown in Settings > Pages, usually:
   https://YOUR-GITHUB-USERNAME.github.io/lakshman-csp/

This package is a ready-to-publish website. It is not yet live on GitHub Pages because publishing requires access to your GitHub account.
